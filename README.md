# Лаунчер

Тестовая сборка.

Скачать: [последний релиз](https://github.com/andreore/game-launcher/releases/latest).
Для Windows берите `setup.exe`, для Linux — AppImage или пакет.

Собирается автоматически по тегу. Как всё устроено, как добавить игру и как
выпустить новую версию: [docs/разработка.md](docs/разработка.md).
