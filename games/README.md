# Папка игр

Одна игра живёт в одной папке со своим `game.json`:

```
games/
├─ змейка/
│  ├─ game.json
│  ├─ cover.png        ← необязательно
│  └─ змейка.exe
└─ танчики/
   ├─ game.json
   └─ танчики.exe
```

Лаунчер обходит эту папку при запуске и по кнопке «Обновить». Подпапки без
`game.json` он пропускает молча. Подпапки с испорченным `game.json` попадают в
предупреждение, а остальные игры остаются на месте.

## Файл game.json

| Поле          | Обязательно | Что это                                        |
| ------------- | ----------- | ---------------------------------------------- |
| `id`          | да          | Идентификатор. Латиница, цифры, `-`, `_`, `.`   |
| `title`       | да          | Название для игрока                            |
| `version`     | нет         | Версия, показывается в списке                   |
| `description` | нет         | Пара фраз об игре                              |
| `author`      | нет         | Кто сделал                                     |
| `tags`        | нет         | Слова, по которым ищет поиск                    |
| `cover`       | нет         | Файл обложки внутри папки игры                 |
| `entry`       | да          | Как запускать, см. ниже                        |

Проще всего скопировать пример в конце страницы.

## Способы запуска (`entry`)

Готовый файл, обычный случай для наших игр:

```json
"entry": { "type": "executable", "path": "змейка.exe", "args": ["--fullscreen"] }
```

`path` указывается относительно папки игры. Выйти за её пределы нельзя, такую
попытку лаунчер отклонит. `args` можно не писать, если аргументов нет.

Программа из PATH, например интерпретатор с игрой-скриптом:

```json
"entry": { "type": "command", "command": "python3", "args": ["main.py"] }
```

Ссылка, если игра живёт в браузере:

```json
"entry": { "type": "url", "url": "https://example.com/play" }
```

## Пример целиком

```json
{
  "id": "snake",
  "title": "Змейка",
  "version": "0.3.0",
  "author": "мы с друзьями",
  "description": "Классика: собираем ягоды и не врезаемся в себя.",
  "tags": ["аркада", "коротать время"],
  "cover": "cover.png",
  "entry": { "type": "executable", "path": "snake.exe" }
}
```
